
# Customer Segmentation and Strategic Priority Scoring using RFM Analysis

## Project Overview
This project analyzes customer purchasing behavior in the Olist Brazilian E-Commerce Marketplace using RFM (Recency, Frequency, Monetary) analysis. It combines customer purchase behavior with review scores and delivery performance to identify customer segments and prioritize retention strategies.

## Problem Statement
E-commerce businesses often struggle to retain customers after their first purchase. This project identifies valuable, inactive, and at-risk customers to help businesses improve customer retention, customer satisfaction, and revenue.

## Objectives
- Perform data cleaning and exploratory data analysis (EDA).
- Calculate Recency, Frequency, and Monetary (RFM) metrics.
- Segment customers into meaningful groups.
- Analyze customer reviews and delivery performance.
- Develop a Strategic Priority Score.
- Estimate Revenue at Risk.
- Provide data-driven business recommendations.

## Dataset
**Brazilian E-Commerce Public Dataset by Olist**

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains anonymized Brazilian e-commerce transactions from 2016–2018.

Datasets used include customers, orders, order items, payments, reviews, products, sellers, geolocation, and product category translations.
